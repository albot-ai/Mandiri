Panduan Penggunaan ModulAjar AI - Pustaka SIBI

Aplikasi ini dirancang 100% berjalan di browser (Client-Side) sehingga aman di-hosting gratis di GitHub Pages.

Langkah 1

Dapatkan Gemini API Key Gratis

  1. Buka Google AI Studio (aistudio.google.com) dan login dengan akun Google Anda.
  2. Klik tombol "Create API Key" lalu salin kode kuncinya.
  3. Klik tombol "Pengaturan & Profil" di pojok kanan atas aplikasi ini, tempel API Key tersebut, dan simpan.
  4. Kunci hanya disimpan di localStorage browser Anda sendiri, tidak pernah dikirim ke server lain.
Langkah 2

Unduh & Simpan Buku PDF SIBI

  1. Unduh buku teks resmi Kurikulum Merdeka (PDF) dari portal SIBI Kemendikbudristek (buku.kemdikbud.go.id).
  2. Buka tab "Pustaka Buku SIBI" di aplikasi ini lalu unggah file PDF tersebut.
  3. Sistem akan mengekstrak seluruh teks halaman dan menyimpannya ke database lokal browser (IndexedDB).
  4. Gunakan tombol "Lihat Isi Halaman" untuk mengecek nomor halaman bab yang ingin diajarkan.
Langkah 3

Susun & Ekspor Modul Ajar

  1. Kembali ke tab "Buat Modul Ajar", pilih buku dari dropdown, dan tentukan rentang halaman materi (misal hal. 1 s.d. 12).
  2. Lengkapi kelas, mata pelajaran, topik, alokasi waktu, dan pilih sintaks model pembelajaran (PBL, PjBL, UbD, dll.).
  3. Klik "Susun Modul Ajar dengan AI".
  4. Unduh hasilnya langsung sebagai file Microsoft Word (.doc) berformat A4 atau cetak ke PDF.
Tips GitHub Pages

Cara Unggah ke GitHub Pages

  1. Buat repositori baru di GitHub (misal: modulajar-ai).
  2. Unggah file tunggal index.html ini ke repositori tersebut.
  3. Masuk ke menu Settings → Pages, pilih branch main dan folder / (root), lalu klik Save.
  4. Dalam 1 menit, aplikasi web Anda aktif secara online dan siap dipakai oleh rekan-rekan guru!
